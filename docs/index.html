Polymarket Auto Bot

Automated sports prediction-market trading service for Polymarket, built on the official polymarket-client Python SDK.

The bot ingests live game signals from upstream monitors and Telegram cappers, matches them to Polymarket prediction markets, applies configurable risk controls, and executes limit orders — either automatically or through a manual approval queue. It runs on Railway (cloud) with a Termux executor (Android phone) for on-device wallet signing.

Overview

Key Capabilities

  • Multi-source signal ingestion — WNBA Predicted Winner calls via Slack webhooks and direct Tailnet feed, NFL/CFB capper picks via Telegram bridge
  • Dual execution mode — Paper trading (simulated) and live trading (real USDC orders) with triple-gate safety
  • Watch-until-price queue — Signals are monitored until the market price reaches the configured limit or the signal expires
  • Risk management — Per-trade caps, daily budget limits, maximum price/spread thresholds, political market blocking
  • Real-time dashboard — Dark-themed web UI with P&L tracking, position management, live/paper mode controls, SELL buttons
  • Termux executor — Android-based order executor for wallet-local signing via the Polymarket SDK
  • Research tooling — Spread capture, scalping analysis, game reconstruction, and backtesting modules

Signal Ingestion Paths

The bot receives trading signals through four independent paths:

Path 1 — Slack Events (WNBA, push)

NBAMonitor sends a Slack alert when a PW call is generated. Slack's Events API pushes the message to the bot's /slack/events webhook.
Latency: ~1–3 seconds from call generation.

Path 2 — PW Export Direct Feed (WNBA, pull)

The bot polls NBAMonitor's /api/pw-export every 8 seconds over the Tailscale VPN. Uses HTTP CONNECT through Tailscale's outbound proxy with TLS.
Latency: ~4–8 seconds average.

Path 3 — NFL Capper Ingest (NFL, pull)

Polls a Telegram-to-HTTP bridge every 15 seconds for NFL picks from professional cappers (SLAM, Syndicate). Parses team names, odds, and unit sizing.

Path 4 — CFB Capper Preview (CFB, pull)

Same architecture as NFL but in preview/validation mode — picks are parsed and validated but never queued for real execution.

Deduplication: Paths 1 and 2 can receive the same WNBA signal. The bot deduplicates via content-hash identity matching (_pw_signal_key() / _identity()), so a signal arriving on both paths executes at most once.

Core Trading Engine

app/main.py — Trading Core

The foundation of the entire application. Provides:

  • FastAPI app instance and lifespan management
  • live_trading_enabled() / auto_trading_enabled() — runtime env var checks (not cached at import time)
  • _quote() — fetches order book from Polymarket's CLOB, calculates best ask/bid and spread
  • _risk_checks() — enforces per-trade cap, daily budget, max price, max spread, political blocking
  • _execute_limit() — places a limit order on Polymarket via the SDK
  • _watch_loop() — background async loop polling the watch queue every AUTO_POLL_SECONDS
  • JSON file storage with threading.Lock and atomic tmp-then-rename writes

app/structured_logging.py — JSON Structured Logging

Configurable JSON log formatter with UTC timestamps, severity levels, and structured trading context fields (event, trade_id, request_id, stage, reason, status). Controlled by LOG_LEVEL.

Dashboard Layer

app/dashboard.py — Web Dashboard (v0.5.3)

Dark-themed HTML dashboard with HTTP Basic authentication. Features: trading parameter display, auto-trading toggle, active watches, pending approvals, execution history, SELL buttons, executor status.

app/dashboard_metrics_v3.py — Reconciliation Engine

Periodic reconciliation of local trade records against on-chain Polymarket state. Detects fills, partial closes, and settlement.

app/dashboard_live_control_v4.py — Slack Trading Mode

Controls paper vs. live for Slack-sourced signals. Railway AUTO_TRADING env var is authoritative and overrides dashboard state.

app/dashboard_filters_v5.py — Trade Filtering

Portfolio value calculation, trade bucketing (paper vs. live), and filtering logic.

app/dashboard_pnl_filters_v6.py — P&L by Mode

Splits P&L history into paper and live buckets with periodic sampling (every 10s, up to 5760 entries).

app/wallet_dashboard.py — Wallet Display

Connects to the Polymarket SDK to display real-time wallet balance, allowance, and portfolio value.

app/live_trading.py — Live Test Endpoints

Protected BUY/SELL endpoints for manual live trading tests. Validates against supported sports market types.

Signal Ingestion

app/slack_ingest.py — Slack Events Ingestion

Receives Slack Events API webhooks at /slack/events. HMAC signature verification, channel filtering, WNBA team name matching (15 teams with aliases), alert age checking.

app/slack_wnba.py — WNBA PW Message Parser

Specialized parser for NBAMonitor "Predicted Winner" messages. Extracts: winner, win probability, consensus, quarter, edge, moneyline odds. Patches slack_ingest at import time.

app/pw_export_ingest.py — Direct PW Feed Poller

Polls NBAMonitor's /api/pw-export via Tailscale VPN. HTTP CONNECT through proxy with TLS, MagicDNS preferred, peer-IP fallback. Bootstrap safety: first poll sets cursor only. Dedup via content-hash.

app/nfl_capper_ingest.py — NFL Capper Polling

Polls Telegram-ChatGPT bridge for NFL picks. Sources: SLAM, Syndicate. 32-team alias dictionary, American odds parsing, unit sizing.

app/cfb_capper_preview.py — CFB Capper Preview

Mirrors NFL architecture for college football in preview/validation mode — parsed and logged but never queued for real execution.

Termux Executor

scripts/termux_executor.py — On-Device Executor

Runs on an Android phone in Termux. Polls the Railway bot's executor queue, signs transactions locally using the Polymarket wallet private key, submits limit orders via SecureClient, monitors fills, reports results back. Emergency max USDC backstop.

app/termux_executor_dashboard.py — Server-Side Queue

Executor pairing via shared secret, queue item lifecycle (pending → claimed → executed → confirmed), TTL-based expiry, heartbeat monitoring.

NBAMonitor (upstream)

Separate upstream system — not part of this repository

A read-only vendored snapshot is kept in research/upstream_nbamonitor/ for reference (pinned to commit 7fc3285).

What NBAMonitor does:

  • Polls ESPN APIs every 30 seconds for live game data (scores, quarter, clock)
  • Evaluates configurable conditions (score differential, momentum, quarter thresholds)
  • Generates Predicted Winner (PW) calls when conditions trigger
  • Sends Slack alerts with structured PW call details
  • Serves /api/pw-export — JSON API returning all PW calls since a given timestamp
  • Runs on a home server accessible via Tailscale VPN

Connection paths:

  1. Slack push: NBAMonitor → Slack → Events API → bot's /slack/events
  2. Direct pull: Bot → Tailscale VPN → NBAMonitor /api/pw-export (HTTPS)

NRLMonitor (research only)

Vendored snapshot of an NRL (Australian rugby league) monitor in research/upstream_nrlmonitor/. Currently research-only — no active NRL ingestion exists. Provides reference architecture for potential league expansion.

Telegram-ChatGPT Bridge

External service that sanitizes and serves Telegram messages over HTTP. NFL and CFB ingest modules poll this bridge for new picks. Hosted separately on Railway.

Safety Gates

Defense-in-depth with 8 independent safety layers:

1 LIVE_TRADING=false (default) — No real USDC can move. All orders are paper.
2 AUTO_TRADING=false (default) — Even if live, automatic signals require manual approval.
3 BLOCK_POLITICAL_AUTO=true (default) — Political markets excluded from automation.
4 Per-trade caps — MAX_AUTO_TRADE_USDC (25), MAX_TRADE_USDC (100)
5 Daily budget — MAX_DAILY_BUDGET_USDC (100) resets at midnight in TRADING_TIMEZONE
6 Market quality — MAX_PRICE (0.95), MAX_SPREAD (0.08)
7 Geoblock — Polymarket eligibility checked before every execution
8 Executor emergency cap — EXECUTOR_EMERGENCY_MAX_USDC (500) hard limit on Termux

Installation

Termux (Android)

Warning: Do not run from Android shared storage (~/storage/downloads). Copy into the Termux home directory first.
pkg update
pkg install python clang rust make pkg-config libffi openssl unzip -y
cd ~
unzip polymarket-auto-bot.zip
cd polymarket-auto-bot
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your configuration

Start the server:

uvicorn app.main:app --host 127.0.0.1 --port 8787

Start the executor:

python scripts/termux_executor.py
Do not run pip install --upgrade pip in Termux — Termux warns that replacing its packaged pip can break the Python package.

Railway (Cloud)

The Railway deployment uses Docker with the provided Dockerfile and start.sh:

  1. Set all required environment variables in the Railway dashboard
  2. Ensure TS_AUTHKEY is set for Tailscale VPN connectivity
  3. The container boots Tailscale in userspace mode, authenticates, then starts Uvicorn

Health check: GET /health (30s timeout, restart on failure, max 10 retries).
